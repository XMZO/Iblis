# Iblis

Iblis for Forge 1.20.1.

> **Support policy**
>
> Only current Minecraft versions are maintained.
> Minecraft 1.12.x and other legacy versions are unsupported.
> Issues for unsupported versions will be closed without investigation.

- Minecraft 1.20.1
- Forge 47+
- Java 17

`iblis` and `iblis_headshots` remain separate mod IDs and are maintained together in this branch.
